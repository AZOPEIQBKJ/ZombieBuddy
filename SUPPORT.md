# Support

This repository supports **ZombieBuddy Community**, initially targeting **PZ 42.21.0**. There is no response-time guarantee. Real solo, Host and dedicated acceptance are pending. Report community issues in [this fork](https://github.com/AZOPEIQBKJ/ZombieBuddy/issues). Do not send community support requests to Zed as if he maintained this distribution.

Include exact game/build and community version, OS, solo/Host/dedicated context, installation route, Mod IDs and Workshop IDs, and a minimal reproduction. Describe whether failure happens before the menu, while approving a Java mod, when loading a world, or after reconnect/restart. Attach only the relevant log window, with paths, IPs, account identifiers, tokens and passwords redacted. Keep stack traces and class names needed to identify the failed path.

Attach the read-only preflight result and reviewed effective launch options when relevant, including launcher JSON **and** Steam/service/script settings. Do not upload an entire user folder, private signing key, approval database, save or proprietary game JAR. Do not bypass signatures or use `allow-all` to make a report pass.

For a suspected trust/signature bypass or private-data exposure, use [GitHub private vulnerability reporting](https://github.com/AZOPEIQBKJ/ZombieBuddy/security/advisories/new), enabled for this repository. Do not post secrets or a working exploit in a public issue. No private support address is established yet.
