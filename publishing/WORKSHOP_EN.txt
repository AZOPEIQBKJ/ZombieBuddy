[h1]ZombieBuddy Community — development preview[/h1]
Independent maintenance of ZombieBuddy by Andrey "Zed" Zaikin, based on version 2.3.3. Maintained by Aftermath Systems under the original MIT licence. This is a community fork, not an official upstream release.

[b]PZ 42.21 loading fixes are integrated into the framework. No separate Aftermath compatibility adapter is required.[/b]

[h2]Current status[/h2]
Development candidate 2.3.3-community.2: 160 Java tests and isolated checks against actual PZ 42.21 bytecode pass. Real gameplay, save/reload, Host, dedicated servers, Linux and macOS remain unaccepted. These checks do not establish multiplayer support or compatibility with every Java mod. This draft is not a stable release announcement.

[h2]Installation and migration[/h2]
Subscribing alone does not install the Java agent. Read the community installation guide before changing launch settings. Retain one active distribution with Mod ID [b]ZombieBuddy[/b] and one effective ZombieBuddy agent across the launcher JSON and Steam/service/script options. Keep unrelated launch options and back up the previous files/settings.
The 42.21 fix needs neither AftermathLHCompat4221.jar nor a patches_jar option. Do not enable the original and community distributions together. A dependent mod that names the original Workshop item explicitly may need a dependency update from its maintainer.
Updates are manual. The original Windows installer belongs to the original distribution; this preview supplies no installer or native DLL. Mod-signature and approval checks remain active. Java mods execute with the permissions of the game process; use trusted sources.
