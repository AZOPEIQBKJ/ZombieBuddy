[h1]ZombieBuddy Community — preview de développement[/h1]
Maintenance indépendante de ZombieBuddy d'Andrey « Zed » Zaikin, basée sur la version 2.3.3. Maintenue par Aftermath Systems sous la licence MIT originale. Ce fork communautaire n'est pas une version officielle de l'auteur initial.

[b]Le correctif de chargement PZ 42.21 est intégré au framework. Aucun adaptateur Aftermath séparé n'est nécessaire.[/b]

[h2]État actuel[/h2]
Candidate locale 2.3.3-community.1 : 148 tests Java et des contrôles isolés sur le véritable bytecode PZ 42.21 réussis. Partie réelle, sauvegarde/reprise, Host, dédié, Linux et macOS restent à réceptionner. Ces contrôles ne prouvent ni le multijoueur ni la compatibilité de tous les mods Java. Ce brouillon n'annonce pas une version stable.

[h2]Installation et migration[/h2]
L'abonnement seul n'installe pas l'agent Java. Lire le guide communautaire avant de modifier les paramètres de lancement. Conserver une seule distribution active avec le Mod ID [b]ZombieBuddy[/b] et un seul agent effectif dans l'ensemble JSON du lanceur + Steam/script/service. Préserver les autres paramètres et sauvegarder les fichiers/réglages précédents.
Le correctif 42.21 ne demande ni AftermathLHCompat4221.jar ni option patches_jar. Ne pas activer ensemble l'original et le fork. Un mod dépendant qui désigne explicitement l'ancien item Workshop peut nécessiter une mise à jour par son mainteneur.
Les mises à jour sont manuelles. L'installateur Windows original appartient à la distribution originale ; cette preview ne fournit ni installateur ni DLL native. Les signatures et approbations des mods restent contrôlées. Les mods Java s'exécutent avec les permissions du jeu ; choisir des sources de confiance.
