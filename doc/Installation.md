# Community installation

For ZombieBuddy Community, follow the [installation guide](Installation_EN.md). It covers migration, effective launch settings, manual updates and rollback. Use one ZombieBuddy distribution and one effective agent. The original installer belongs to the upstream distribution.

The original installation instructions remain in the [upstream history](https://github.com/zed-0xff/ZombieBuddy/blob/0ddf161c27848f12d09e74de7fadbea9d50e621d/doc/Installation.md).
