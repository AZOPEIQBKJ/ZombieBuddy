# Community installation / Installation communautaire

For ZombieBuddy Community, follow the [English guide](Installation_EN.md) or [French guide](Installation_FR.md). These include migration, effective launch settings, manual updates and rollback. The original installer belongs to the upstream distribution.

Les guides ci-dessus concernent le fork ; utiliser une seule distribution ZombieBuddy et un seul agent effectif. Les anciennes captures de configuration ne sont plus distribuées.

The original installation instructions remain available in the [upstream history](https://github.com/zed-0xff/ZombieBuddy/blob/0ddf161c27848f12d09e74de7fadbea9d50e621d/doc/Installation.md).
